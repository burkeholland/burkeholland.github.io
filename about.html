About Me

I'm Burke Holland. Web developer based in Nashville, TN. I've been building things for the web for a while now, and then AI showed up and changed what that actually means.

Not in the "write code faster" sense. In the "I just built something I couldn't have built before" sense. Things that were too expensive, too complex, too whatever to touch before. That gap has been closing fast. I've watched it close firsthand. You can't unsee it.

Most of what I write about is what changes when the cost of building drops. What stays the same. What we might be giving up for the speed. See what I've been building →
